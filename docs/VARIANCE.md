# Run-to-run variance

Generated by `graphbench compare`. Do not edit by hand.

Comparing 2 runs of identical configuration: `20260825T064625Z`, `20260825T072533Z`.

Spread is the range as a percentage of the smaller value, not a standard deviation: with 2 runs a range is all the data supports. Abs is the same difference in the metric's own units.

A row is **unstable** when the spread exceeds 25% *and* the absolute difference clears a per-metric floor. Both conditions are needed: 0.04ms against 0.20ms is a 338% spread and 0.16ms of real difference, which is the resolution of a Python-timed client call rather than engine instability. Rows that clear the percentage but not the floor say so.

A single run's figure for an unstable metric is not a measurement and should not be used to rank engines.
